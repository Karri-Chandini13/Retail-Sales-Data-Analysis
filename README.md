# Retail Sales Data Analysis using Python & Pandas

## Project Overview
This project analyzes retail sales data using Python, Pandas, and Matplotlib to understand product performance, regional sales, and category-wise trends.

## Objectives
- Explore and clean retail sales data.
- Identify missing values and duplicate records.
- Calculate total sales and average sales.
- Find top-selling products and high-performing regions.
- Analyze category-wise sales and quantities.
- Export analysis results to Excel.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Excel
- CSV

## Key Features
- Data exploration and cleaning
- Sales calculation using quantity, unit price, and discount
- Product-wise, region-wise, and category-wise analysis
- Top 5 products by sales
- Bar charts and pie chart visualization
- Multi-sheet Excel report and summary

## How to Run

Install the required libraries:

```bash
python -m pip install pandas matplotlib openpyxl
```

Keep `sales_analysis.py` and `sales_data.csv` in the same folder, then run:

```bash
python sales_analysis.py
```

## Project Files
- `sales_analysis.py` — Python analysis script
- `sales_data.csv` — Practice dataset
- `Sales_Analysis_Report.xlsx` — Excel report
- `product_sales_chart.png` — Product sales chart
- `region_sales_chart.png` — Region sales chart
- `category_sales_chart.png` — Category sales chart
